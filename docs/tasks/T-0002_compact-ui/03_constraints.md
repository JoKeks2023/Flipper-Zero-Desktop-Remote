# Grenzen

- Nutzerpräferenz „kompakt, sachlich und dicht“ hat Vorrang vor luftiger macOS-Optik.
- Native Qt-Widgets beibehalten, keine WebView, keine neuen Abhängigkeiten.
- Keine Änderungen am Transport, Geräteprotokoll oder Expert-/Easy-Mode-Rechten.
- Referenz: Skill jorisconrad-design-language (neutrale Oberflächen, ein Akzent,
  sparsame Rahmen, Satzschreibweise, konsistente Glyphen und erkennbare Zustände).
- Keine Simulatoren oder schweren lokalen Builds.
