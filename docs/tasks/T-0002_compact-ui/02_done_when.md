# Abnahme

- Keine generischen Plattform-Cliparts oder großflächige Karten-Startseite.
- Kleine Navigationsgruppen und kompakte UI-Typografie.
- Display begrenzt, unverzerrt und in ganzzahligen Pixelstufen dargestellt.
- Dateiliste und Vorschau gleichzeitig sichtbar.
- Tastatur-/Accessibility-Navigation, Live-Verbindung und Dateiaktionen erhalten.
- Echte App visuell prüfen; Regressionstests aus T-0001 bleiben grün.
