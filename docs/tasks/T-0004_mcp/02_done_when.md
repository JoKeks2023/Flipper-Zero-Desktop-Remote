# Abnahme

- MCP-Client kann Tools auflisten und über die laufende App tatsächliche Daten lesen.
- Oberfläche bleibt während MCP-Gerätearbeit bedienbar.
- Ohne Freigabe kein Zugriff; Lesemodus sperrt Bedienung, Widerruf sperrt neue Aktionen.
- Beschäftigte Verbindung liefert erklärten Fehler; kein zweiter USB-Besitzer.
- Fehler liefern MCP-Fehlerresultate und werden nicht als Erfolg ausgegeben.
- Display als Bildinhalt, vollständige Client-Einrichtung und verständliche UI.
- Tests und Runtime-Nachweis im Repo dokumentiert; Plattformgrenzen benannt.
- Allgemeine Einstellungen beeinflussen Verhalten und bleiben gespeichert;
  Credits, MIT-Lizenz und Abhängigkeitshinweise sind in der App erreichbar.
