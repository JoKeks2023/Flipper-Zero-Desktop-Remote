# Abnahme

- Angezeigte Werte stimmen mit den tatsächlich vom Gerät gemeldeten Werten überein.
- Keine Gleichsetzung von USB-Verbindung und aktivem Laden.
- Fehlende/ungültige Daten werden nicht als Null oder alte aktuelle Werte angezeigt.
- Trennen leert das Dashboard; Hintergrundabfragen unterbrechen keine Live-Ansicht.
- Manueller Refresh, automatische Abfrage und Gerätedetails in der laufenden App prüfen.
- Startseite im unterstützten Mindestfenster ohne horizontales Abschneiden nutzbar.
- Regressionstests, neue Datentests und dokumentierte Runtime-Evidence.
