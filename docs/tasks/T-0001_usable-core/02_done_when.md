# Abnahme

- Flet aus Quellcode, Abhängigkeiten und Packaging entfernt.
- Qt-App startet; Module lassen sich tatsächlich bedienen.
- Geräteinfo und Dateilisten am angeschlossenen Momentum-Gerät geprüft.
- Antwortgrenzen, Timeout/Abbruch und Fehlerzustände getestet.
- Dateien mit Leerzeichen korrekt auswählbar; keine erfundenen Dateien.
- Kein Gerät erforderlich für Regressionstests.
- Linux nur als verifiziert bezeichnen, wenn dort tatsächlich ausgeführt.
